# ADR-008: Next.js для публичного сайта и панелей

**Статус:** Accepted

## Решение

Public Web и admin interfaces реализуются на Next.js/TypeScript и работают только через versioned APIs.

## Последствия

Поддерживаются SSR/SSG, multilingual/RTL и общие UI primitives; точное размещение Site Admin — OD-06.
