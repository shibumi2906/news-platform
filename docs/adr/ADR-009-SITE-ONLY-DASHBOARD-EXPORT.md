# ADR-009: Данные в дашборд отправляет только сайт

**Статус:** Accepted

## Решение

Только Site Analytics Exporter отправляет согласованные events/aggregates в Supabase через локальный transactional outbox. Интегратор не имеет подключения к Supabase.

## Последствия

Дашборд отражает состояние сайтов и согласованные бизнес-метрики; локальная наблюдаемость интегратора остаётся внутри установки.
