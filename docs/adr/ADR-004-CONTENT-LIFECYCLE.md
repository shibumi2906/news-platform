# ADR-004: Жизненный цикл контента

**Статус:** Accepted

## Решение

`Source Material → Event/Stage → Canonical News Package → Incoming Package → Site Article/Version → Publication`.

## Последствия

Владение данными однозначно; входящий package immutable; редакционные изменения сайта не перезаписываются интегратором.
