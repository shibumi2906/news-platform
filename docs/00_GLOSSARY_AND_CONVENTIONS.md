# Глоссарий и соглашения

**Статус:** Draft 0.1  
**Зависимости:** `00_INDEX.md`

## 1. Основные термины

### Продукты и установки

- **Платформа** — совокупность совместимых шаблонов интегратора, сайта, общих контрактов и библиотек.
- **Шаблон интегратора** — тиражируемая кодовая база для создания отдельной установки интегратора.
- **Шаблон сайта** — тиражируемая кодовая база для создания отдельного новостного сайта.
- **Экземпляр / установка (`instance`)** — самостоятельно развёрнутая копия шаблона со своей БД, конфигурацией и панелью.
- **Интегратор (`integrator`)** — отдельная установка, которая находит и обрабатывает материалы и доставляет новостные пакеты сайтам.
- **Сайт (`site`)** — отдельная установка публичного новостного портала, которая принимает пакеты, создаёт собственные редакционные версии и публикует их.
- **Подключение (`connection`)** — настроенная и авторизованная связь конкретного интегратора с конкретным сайтом.
- **Дашборд** — внешняя аналитическая система на Supabase. Данные в неё отправляет только сайт.

Термины `tenant` и «единая мультитенантная установка» не используются для описания основной модели продукта.

### Контент

- **Источник (`source`)** — сайт, RSS, API, YouTube-канал или поисковый механизм, из которого получены сведения.
- **Исходный материал (`source_material`)** — нормализованная запись одной публикации одного источника.
- **Технический дубль** — повторное получение той же публикации или идентичного документа.
- **Смысловой дубль** — другой материал о том же событии без существенных новых фактов.
- **Событие (`event`)** — реальное событие развлекательной индустрии: анонс, кастинг, трейлер, премьера, релиз, перенос, отмена, награда, результат проката и т. п.
- **Стадия события (`event_stage`)** — существенное развитие события, например `rumor → announcement → trailer → premiere`.
- **Событийный кластер (`event_cluster`)** — группа исходных материалов и стадий, относящихся к одной линии события.
- **Канонический новостной пакет (`canonical_news_package`)** — сформированный интегратором структурированный пакет для передачи сайту: карточка, факты, источники, языковые версии, медиа и служебные данные.
- **Входящий пакет (`incoming_news_package`)** — неизменяемая принятая сайтом копия канонического пакета.
- **Материал сайта (`site_article`)** — самостоятельная редакционная сущность сайта, созданная из входящего пакета.
- **Версия материала (`article_version`)** — сохранённое состояние материала сайта после редакционного изменения.
- **Языковая версия (`language_version`)** — текст и метаданные материала на одном целевом языке.
- **Публикация (`publication`)** — размещение конкретной версии материала на сайте или внешнем канале.

### AI

- **AI-операция** — ограниченная задача со строгим входом и выходом: классификация, извлечение фактов, summary, перевод и т. п.
- **Экономичная модель** — модель массовой обработки с приемлемой стоимостью и качеством.
- **Мощная модель** — модель для сложных, спорных или низкоуверенных случаев.
- **Маршрутизатор моделей** — компонент выбора провайдера и модели по политике операции.
- **Уверенность (`confidence`)** — оценка результата, используемая вместе с детерминированными проверками; не считается доказательством истинности.
- **Версия промпта** — неизменяемый идентификатор шаблона инструкции AI.

## 4. Идентификаторы и время

- Внешние и основные доменные идентификаторы — UUID.
- Каждая установка имеет стабильный `instance_id` и `instance_type` (`integrator` или `site`).
- Идентификаторы, передаваемые между системами, не переиспользуются.
- Все timestamp хранятся и передаются в UTC, ISO 8601.
- Интерфейс отображает время в настроенной временной зоне установки.
- API использует `snake_case`; TypeScript-клиенты могут преобразовывать имена только на границе клиента.
- Денежные значения передаются целым числом в минимальных единицах валюты и с ISO 4217 `currency`.

## 5. Версионирование

- HTTP API: `/api/v1/...`.
- Контракты сообщений: `schema_version`.
- Новостной пакет имеет `package_id`, `package_version` и `updated_at`.
- Повторная доставка одной версии использует один `idempotency_key`.
- Изменение обязательного поля или смысла поля требует новой major-версии контракта.

## 6. Нормативные слова

- **ДОЛЖЕН / MUST** — обязательное требование.
- **НЕ ДОЛЖЕН / MUST NOT** — запрет.
- **СЛЕДУЕТ / SHOULD** — рекомендуемое поведение; отклонение требует объяснения.
- **МОЖЕТ / MAY** — допустимая возможность.

## 7. Соглашения о статусах

Статусы хранятся как контролируемые перечисления. Произвольные значения запрещены. Для расширения создаётся миграция и обновляются контракт, документация и тесты.

Базовый редакционный поток сайта:

```text
received → processing → draft → needs_review → approved
→ scheduled/publishing → published → corrected/unpublished/archived
```
